# Security Policy

## Supported Versions

Security updates are provided for the latest available release of EverSmooth Optimized.

| Version | Supported |
|---|---|
| Latest release | ✅ |
| Older releases | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability affecting EverSmooth Optimized, please report it privately.

**Do not disclose security vulnerabilities through public GitHub Issues.**

You can report vulnerabilities through:

- **GitHub Private Vulnerability Reporting:** Use the repository's Security tab if private reporting is enabled.
- **GitHub Contact:** [Contact the maintainer](https://github.com/ReysoKree).

## What to Include

Please provide as much relevant information as possible:

- A clear description of the vulnerability.
- The affected modpack version.
- The affected Minecraft version and mod loader version.
- Steps to reproduce the issue.
- Relevant logs, screenshots, or other supporting evidence.
- Potential impact of the vulnerability.

## Responsible Disclosure

Please allow the maintainer reasonable time to investigate and address a reported vulnerability before publicly disclosing it.

Please avoid exploiting vulnerabilities, accessing other users' data, or disrupting services while investigating or reporting security issues.

## Security Updates

Confirmed security issues may be addressed through updated releases, dependency updates, mod replacements, or other appropriate changes.

Users are encouraged to keep their modpack installation and included components up to date.

## Third-Party Dependencies

EverSmooth Optimized includes third-party Minecraft mods and resource packs.

These components are maintained by their respective authors and may have independent security policies and update schedules.

For vulnerabilities originating in third-party components, users may also need to contact the respective maintainers.

---

Thank you for helping keep EverSmooth Optimized and its community safer.
